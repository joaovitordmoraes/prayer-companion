# Prayer Companion

A mobile application built with React Native and Expo to help users with their prayer routines.

## 🚀 Technologies

- [Expo](https://expo.dev/) - Framework for building cross-platform mobile applications
- [React Native](https://reactnative.dev/) - Framework for building native mobile apps using React
- [TypeScript](https://www.typescriptlang.org/) - Typed superset of JavaScript
- [NativeWind](https://www.nativewind.dev/) - Utility-first CSS framework for React Native
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [React Navigation](https://reactnavigation.org/) - Routing and navigation for React Native apps
- [Lucide React Native](https://lucide.dev/) - Beautiful & consistent icons

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- Node.js (LTS version recommended)
- npm or yarn
- iOS Simulator (for Mac users) or Android Studio (for Android development)

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/prayer-companion.git
cd prayer-companion
```

2. Install dependencies:
```bash
npm install
```

## 🚀 Running the App

1. Start the development server:
```bash
npx expo start
```
or
```bash
npm start
```

2. Choose your preferred way to run the app:
- Press `i` to run on iOS simulator
- Press `a` to run on Android emulator
- Scan the QR code with the Expo Go app on your physical device

## 📱 Available Scripts

- `npm start` or `yarn start` - Starts the Expo development server
- `npm run android` or `yarn android` - Starts the app on Android
- `npm run ios` or `yarn ios` - Starts the app on iOS
- `npm run web` or `yarn web` - Starts the app in web mode
